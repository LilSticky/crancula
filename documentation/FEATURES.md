These are the intended features and requirements for Crancula.

# General Requirements
   - [ ] Standalone desktop application
   - [ ] Digital library of songs
   - [ ] Manual creation and editing of punched tapes
   - [ ] Customizable settings for in- and outputs
     - Input Formats:
       - Song:
         - [ ] Midi
       - Scores:
         - [ ] MusicXML
     - Output Formats
       - Tape:
         - [ ] SVG
         - [ ] DXF
         - [ ] PDF
         - [ ] PNG
       - Scores:
         - [ ] MusicXML
         - [ ] PDF
         - [ ] PNG
       - Song:
         - [ ] MP3
         - [ ] WAV
         - [ ] MIDI

# Features
1. **Organs:**
   - [ ] Define Organ model
     - [ ] Tape settings
     - [ ] Define Pipe model
   - [ ] Implement Organ list
     - [ ] Create Organ → Organ form
     - [ ] Edit Organ → Organ form
     - [ ] Delete Organ
   - [ ] Implement Organ form
     - [ ] Implement Pipe form
2. **Songs:**
   - [ ] Upload song (see "Input Formats > Song" above)
   - [ ] Download song as sound file (see "Output Formats > Song" above)
3. **Tapes:**
   - [ ] Convert songs to tapes
   - [ ] Convert tapes to songs
   - [ ] Edit tapes
   - [ ] Download tapes (see "Output Formats > Tape" above)
4. **Scores:**
   - [ ] Upload scores (see "Input Formats > Scores" above)
   - [ ] Download scores (see "Output Formats > Scores" above)
