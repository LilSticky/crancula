# Chapter 4: Tape Editor

**Goal**: Interactive visual editor for punched tape with zoom, scroll, and hole editing.

- [ ] Render Tape as a scrollable grid (rows = pipes, columns = time units)
- [ ] Draw holes as filled rectangles on the grid
- [ ] Click/drag to add or remove holes
- [ ] Zoom controls (time axis zoom)
- [ ] Snap-to-grid for precise hole placement
- [ ] Real-time dimension overlay (tape width indicator, hole spacing guides)
- [ ] Keyboard shortcuts (undo/redo, delete, select all)
- [ ] Unit & component tests for editor interactions
